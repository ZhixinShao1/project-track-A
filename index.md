# TurtleBot3 Visual Waypoint Navigation and Docking

**UTS 41014  Sensors and Control for Mechatronic Systems**

**Track A: Visual Waypoint Navigation**

[Code Repository](https://github.com/ZhixinShao1/project-track-A) | [README](https://github.com/ZhixinShao1/project-track-A/blob/main/README.md)

## Abstract

This project develops an autonomous navigation and visual docking system for a simulated TurtleBot3 Waffle Pi robot using MuJoCo.

The system combines wheel encoders, 2D LiDAR, ArUco marker detection, EKF localisation and feedback control.

## System Design

The system includes sensing, state estimation, waypoint navigation, obstacle avoidance and visual docking.

## Experimental Results

The system was evaluated across four conditions with five trials per condition.

| Condition | Success Rate |

| Nominal | 100% |
| High Encoder Noise | 100% |
| High Camera Noise | 0% |
| Shifted Obstacle | 100% |
